# 制約事項 (仕様書14章)

- **粉じん濃度の厳密な法令・環境基準判定には使用しないこと。** 本モデルは
  相対リスクスコア(0-100)であり、物理濃度[μg/m³]を予測するものではない。
- 10m・20m等のローカルメッシュは表示・局所拡散計算の解像度であり、GSMの
  気象解像度(約10km, 0.1度×0.125度)そのものではない。GSMの現場地点風を
  最近傍または双線形補間で取得し、その風をローカルメッシュ全体に一様に
  与える方式である(建物近傍での風の変化は表現できない)。
- 建物による風の回り込みや乱流は未考慮である。
- 発生量(`E_base`)は工事種類・土質・含水率・車両走行等で実際には変わるが、
  現段階では工事強度(small/medium/large)に応じた設定値である。
- 積算降水量の差分にはごくわずかな非単調性(浮動小数点誤差・空間補間起因)
  が生じることがあり、0へ切り詰めて処理している(`docs/grib_spec.md`参照)。
- 将来的には、現地の風向風速計・粉じん計・散水実績を用いて係数を校正する
  ことを想定している(現時点では未実装)。
- 出力図には必ず「テスト版」「相対リスク」「気象データ出典」を明記する
  (`plotting.py` のフッター)。
- Streamlit画面(`app.py`)は、Chromeブラウザ拡張等を用いた自動クリック
  操作までは本プロジェクトの開発中に実施していない。`streamlit run app.py`
  でサーバが正常起動し例外なくレンダリングされることは確認済みだが、
  実際のボタン操作を伴う対話フローは手動での確認を推奨する。
